# Bare Vampire Survivors

A Vampire Survivors-style game on [Bare Engine](https://github.com/bare-engine/bare-engine), built to stress-test the engine's rendering, arcade physics and camera.

Run `npm run dev` and open the URL. Add `?bench` to the URL to start the benchmark automatically.

| Keys | |
| --- | --- |
| WASD / arrows / hold mouse | Move. Knives fly towards the mouse. |
| Wheel, `-` `=`, `0`, `Z` | Zoom, reset zoom, overview of the whole arena |
| `Esc` | Pause |
| `M` | Switch collisions between the engine's arcade physics and the game's own spatial grid |
| `B` | Benchmark: ramps enemy counts in both collision modes, prints a table to the console |
| `1` `2` `3` | Add 100 / 500 / 2000 enemies |
| `K` `G` `F` `V` `N` `H` | Kill all, god mode, freeze spawner, decor on/off, minimap, help |

The perf panel (top left) times the engine's fixed update, arcade physics, update and render each frame, and shows draw calls. In the browser console, `game` and `perf` are available.

Sprites are generated by `node tools/generateArt.cjs`.

<h2>Getting Started</h2>

Install <a href="https://nodejs.org/en/download">Node</a> and <a href="https://git-scm.com/download/win">Git</a><br><br>
<ol>
    <li>Click Code->"Download ZIP" - unzip</li>
    <li>Open the command line in the unzipped folder</li>
    <li>Run <code>npm install</code> + <code>npm run dev</code></li>
    <li>Ctrl-click the localhost URL shown in the command line.</li>
</ol>
<br>Or:<br>
<ol>
    <li>Click "Use this template" in the top right - create the repo.</li>
